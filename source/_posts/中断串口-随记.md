# 没有触发回调

由于优化代码的缘故 TxCplt 或者 RxCplt 函数需要 待发送寄存器或者接收寄存器满了才会触发 相应的回调

在没有调用或者数组没满都不会触发

# IT 串口 溢出

接收 armed 的字节数 < 实际发来的字节数时,多出来的字节到达时接收没重新 arm,硬件置溢出错误(ORE)。ORE 不清除,USART 就停止再触发接收中断,之后发什么都没反应。

# 收发如果使用同一个缓冲区的话

使用同一个缓冲区在收发过快的时候，会导致数据错乱

# 错位一个字节

固定长度收发导致寄存器残留导致错位

开发板上按复位键

# Event 不定长度收发

不是DMA 中断，而是IDLE  总线空闲中断

DMA 不是 cpu 本体的工作

HAL_UARTEx_RxEventCallBack回调函数在 调用HAL_UARTEx_ReceiveToIdle_IT 时 被触发
