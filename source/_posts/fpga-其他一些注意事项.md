# 有符号的寄存器

寄存器默认被声明为无符号的，你需要signed它才行

比如\`reg signed [31:0] int \`//这里声明了31-0+1位宽的有符号寄存器

# 在移位有符号的寄存器的时候注意

对于有符号的寄存器做有符号移位和无符号移位是不同的

| 运算符 | 右移时左边补什么 |

| \`>>\` | 始终补 \`0\` |

| \`>>>\` | 左操作数是有符号类型时，补符号位；否则补 \`0\` |

否则会导致不可预料而且难以检查的行为

## 举个栗子

**右移时，要分清补 `0` 还是补符号位**

以 `b = -8` 为例：

```plain
// b 的二进制是 1111_1000

b >>  1   // 0111_1100，结果是 124
b >>> 1   // 1111_1100，按有符号数解释是 -4
```

# 查找警告信息当中的implicit

处理方法是检查拼写，并明确声明：

```plain
wire [7:0] temp;

```

也可以在自己的代码文件开头使用：

```plain
`default_nettype none

```

这样，原本会创建隐式网络的地方就会报错
