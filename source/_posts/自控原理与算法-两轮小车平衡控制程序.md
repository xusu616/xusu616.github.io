# 使用三个控制环

分别有直立环速度环，转向环

原本的代码段在这里

```C
void EXTI15_10_IRQHandler(void)
{
    if (mpu_dmp_get_data(&pitch, &roll, &yaw) == 0)
    {
        // ========== 1. 直立环参数 ==========
        measure = roll;          // 当前实际倾斜角
        calcu = zhongzhi;        // 目标平衡角

        // ========== 2. 速度环参数 ==========
        // 取左右两轮编码器反馈的平均值
        velocity_measure =
            (read_encoder2() + read_encoder3()) / 2.0f;

        // ========== 3. 转向环参数 ==========
        yaw_measure = yaw;       // 当前偏航角

        // ========== 4. PID 计算 ==========

        // 直立环 + 速度环
        PWM0 = vertical_PID_value(measure, calcu)
             + velocity_PID_value(velocity_measure, velocity_calcu);

        // 转向环（只计算一次）
        float turn_pwm = turn_PID_value(yaw_measure, yaw_calcu);

        // 左右电机差速控制
        PWM1 = PWM0 + turn_pwm;
        PWM2 = PWM0 - turn_pwm;

        // PWM 限幅
        PWM_Xianfu(7000, &PWM1, &PWM2);
    }

    // 此处还需要按照使用的 STM32 库清除对应中断挂起标志
}
```
